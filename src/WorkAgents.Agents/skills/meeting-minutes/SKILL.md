# 議事録整形スキル

## 適用範囲
会議メモ・文字起こし・議論ログを、社内共有用の議事録 Markdown に変換するとき。

## 出力フォーマット(Markdown)

```markdown
# <会議名>(<YYYY-MM-DD>)

- 開催: <YYYY-MM-DD HH:mm〜HH:mm>
- 参加者: <A, B, C>
- 議題: <1. ... / 2. ...>

## 決定事項
- <決定1>(責任者: ...)
- <決定2>

## 議題ごとの議論
### 1. <議題>
- <論点・発言要旨>

## アクションアイテム
- [ ] < todo>(担当: <name>, 期限: <YYYY-MM-DD>)
- [ ] < todo>(担当: <name>, 期限: <YYYY-MM-DD>)

## 次回
- 次回開催: <YYYY-MM-DD HH:mm>
- 持越し議題: <...>
```

## 記述規約
- 発言者は敬称略で「姓のみ」またはロール表記。
- 議論は「1 議題=1 小見出し」。同一見出し部で起承転結を整理しない(簡潔な箇条書き)。
- 行動は必ず「担当 / 期限」を付ける。不明は「期限: 未定」と書く。
- メモにない内容は書かない。推測は末尾に `(推測: <根拠>)` で注記。
- 改行は意味段落ごとに 1 行空け、羅列を避ける。

## 入れ子項目
- 関連文書へのリンクがある場合は「## 関連リンク」末尾に列挙。
- 機密フラグが必要な会合は先頭に `> 機密: <レベル>` 行を置く。
